1

确认身份

从私信里的专属链接打开，直接认出你。没有链接就输手机号。

2

传照片

点 02 那个按钮。正脸、背景越简单越好——白墙前拍的抠得最干净。

3

等抠图

AI 自动去背景。第一次要下 81MB 模型，之后就不用了。

4

调位置

四个滑杆调大小 / 旋转 / 上下 / 左右，把脸放到圆框中间偏上，然后下载。

5

设到 Lark

Mine → 点自己的名字 → Edit Profile → 点头像 → 选刚下载的图。

⏳
第 3 步转圈很久——看小字，写着「下载模型 x%」就是正常的。 务必连 wifi，81MB 走流量很贵。
✂️
边上有残留 / 缺了头发——换张背景更简单的重传。 逆光、和背景同色的衣服最容易出问题。
⬇️
在本文档里点下载没反应——浏览器会拦掉文档内的下载。 右键预览图 → 图片另存为，按钮上也写着这句。
